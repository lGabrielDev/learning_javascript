## Criando uma array []

Padraozinho...

```js
// array somente com String
let names = ["batman", "naruto", "hinata"];
console.log(names);



// array somente com Numbers
let numbers = [1,2,3, 50];
console.log(numbers);



// array com qualquer tipo de dado
let arrayComAPorraToda = [
     "batman",
     33,
     {
          name: "naruto",
          age:33,
          printar: function(){return "salve"}
     }
] ;


console.log(arrayComAPorraToda);
console.log(arrayComAPorraToda[0]);
console.log(arrayComAPorraToda[0]);
console.log(arrayComAPorraToda[2].printar());
```

📖 Uma mesma array pode receber diferentes tipos de dados.

## Alterando um item de uma array
Padraozinho....

```js
// Alterando um item de uma array
let names = ["batman", "naruto", "hinata"];

names[0] = "batman2";
console.log(names[0]); //batman2
```

## Adicionando itens numa array
Aqui no js, uma array tem um tamanho dinâmico. Se parece com as listas do Java.

```js
let names = [];

names = ["batman", "naruto", "hinata"];

names[3] = "superman";
names[4] = "ben 10";
console.log(names.length); //4
console.log(names);
```

<br>

Outra forma de adicionar, seria usando o `push()`

```js
let names = ["name1", "name2"];

names.push("novo item");
names.push(33);
names.push(
     {
          name: "tal",
          age: 33
     }
);

console.log(names); 
console.log(names.length) //5
```
