# Os methods mais usados na Array:

<br>

Os principais methods para percorrer uma estrutura de dados/array aqui no Js são:

- `forEach()`
- `filter()`
- `map()`
- `reduce()`

<br>

📖 No fim, todos esses methods estão percorrendo cada item dessa array.

<hr>
<br>

## forEach()

Padraozinho... Igual no Java. 

**Aqui temos uma operação terminal**. Depois dela não é possível chamar mais nenhum method. Isso, porque o method forEach() retorna void.

```js
let listaInsana = ["naruto", "sasuke", "goku", "superman"];

listaInsana.forEach(function(item){
     console.log(item);
});

//ou melhor.... usando arrow function
listaInsana.forEach( item => {
     console.log(item);
});
```

<hr>
<br>

## filter()

Aqui, temos uma **operacao intermediaria**. Depois dela, podemos chamar outros methods. Isso, porque o filter() retorna uma lista.

filter() vai retornar apenas os itens que tiverem dentro da condicao true

```js
//filtrando somente os numeros PAR / EVEN
let listaInsana = [10, 20, 7, 3];

const dsadsa = listaInsana
     .filter( item => item % 2 == 0) //operacao 
     .forEach( i => console.log(i) );

```

## map()

Aqui, temos uma **operacao intermediaria**. Depois dela, podemos chamar outros methods. Isso, porque o map() retorna uma lista.

Igual no Java, o map() transforma nosso item em outro item.

```js
 let listaInsana = [10, 20, 7, 3];
console.log(listaInsana);

let listaAtualizada = listaInsana.
     map( item => item * 2);
     
console.log(listaAtualizada);
```

<hr>
<br>

📖 Importante lembrar que em todos essas functions, estamos percorrendo cada item da array.
