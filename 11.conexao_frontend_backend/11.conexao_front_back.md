## Como concetar front com back -->  caminho de um software PONTA A PONTA

Não importa se é em JavaScript, Java, Python ou C#: toda linguagem tem a sua "ferramenta" (uma classe ou função) que serve para abrir o navegador "por baixo dos panos", enviar os dados pela rede e esperar a resposta. Elas são os Clientes HTTP.

<br>

No Java, você usa o Jackson (através do ObjectMapper) para transformar String em Objeto e vice-versa. No JavaScript, isso é ainda mais simples porque o JSON nasceu dentro do JS.

Você vai usar o objeto global JSON (tudo maiúsculo), que já vem embutido na linguagem.
