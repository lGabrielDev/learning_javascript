## Relembrando

```js
//maneira tradicional
function function1(name){
     return `Salve ${name}`;
}
console.log(function1("rosana"));


//function expression - Criando a function dentro de uma variable
const functionAsVariable = function(name){
     console.log(name + " Salve!");
} 
functionAsVariable("naruto");
```

## Arrow functions

Uma outra forma de escrever functions. Eh tudo a mesma coisa..... O legal, eh que aqui parece as lambda 
expresions do Java.


| parametros/corpo                           | expressao                  |   |   |   |
|-------------------------------------   |----------------------------|---|---|---|
| sem parametros                              | `() => true;`               |   |   |   |
| 1 parametro                                    | `p => true;`                |   |   |   |
| varios parametros                           | `(p1, p2) => true;`          |   |   |   |
| ------------                                      | ------------               |   |   |   |
| corpo do method simples              | `(p1, p2) => true;`          |   |   |   |
| corpo do method com bastante código | `(p1, p2) => {return true};` |   |   |   |

<br>

Denovo, vamos colocar a function dentro de uma variable.




```js
// functions sem parametros
const f1 = () => console.log("salve");
f1();

const f2 = () => 1 > 2; 
console.log(f2()); //false


// functions com 1 parametro. varias formas de fazer... igual no java
const f3 = n1 => n1 + 4;  
console.log(f3(10)); //14

const f4 = (n1) => n1 + 4;
console.log(f3(10)); //14


// functions com vários parametros
const f5 = (n1,n2,n3,n4) => {
     console.log("salve ninjas!: \n")
     console.log(n1);
     console.log(n2);
     console.log(n3);
     console.log(n4);
}
f5("paulo","naruto","batman","kakashi");


//corpo da function simples
const f6 = () => console.log("pokemon");
f6();


//corpo da function com vários códigos
const f7 = () => {
     console.log("pokemon");
}
f7();
```
