## Function Expressions

Basicamente, voce pode armazenar uma funcao em uma variable.

```js
//maneira tradicional de criar uma function
function sum(n1, n2){
     return n1 + n2;
}
console.log(sum(3,1));

//function expression. Ou seja, armazenando uma funcao numa variable
//meio que o nome da funcao se torna o nome da variable. Sacou?
const somarInsano = function(n1 , n2){
     return n1 + n2;
}
console.log(somarInsano(10,2))

```

📖 É um outro jeito de criar uma funcao. Apenas isso.

##  Armazenando uma function dentro de uma variable

```js
function criarPessoa (name){
     //return {name: name};
     return {name};// eh a mesma coisa.
}

//armazenando a function dentro de uma variable
const variableTal1 = criarPessoa;

//armazenando o retorno da function. "( )"
const variableTal2 = criarPessoa("joaozin")

console.log(variableTal1("naruto")); //é uma function
console.log(variableTal2); //é uma variable
```

<br>

📖 Se você usou o `()`, entao a function foi executada.
