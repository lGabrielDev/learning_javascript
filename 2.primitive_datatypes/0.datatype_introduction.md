<h1 align="center"> DataType <img src="https://cdn-icons-png.flaticon.com/512/7020/7020002.png" alt="" width="90px" align="center"></h1>

DataType são os tipos de dados de uma variable.

<br>

No JavaScript nós temos os primitive datatypes e os objetos.

Os primitive datatypes são:

- `String` --> texto / conjunto de characters

- `Number` --> recebe todo tipo de número (integer / flutuantes). Ele é como se fosse um double, por isso consegue receber todo tipo de number.

- `Boolean` --> true or false

- `Null` --> null ou vazio

- `Undefined` --> declaramos a variable, mas nao atribuimos nenhum valor



<br>

Para encontrar o datatype de uma variable/object, vamos usar o `typeof`:


```js
let n1 = "texto";
let n2 = 'texto';

let n3 = 50;
let n4 = 50.55;

let n5 = false;

let n6 = null;

let n7;

console.log(typeof n1); //string
console.log(typeof n2); //string

console.log(typeof n3); //number
console.log(typeof n4); //number

console.log(typeof n5); //boolean

console.log(typeof n6); //object

console.log(typeof n7); //undefined
```
