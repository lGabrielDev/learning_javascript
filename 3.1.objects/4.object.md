No Javascript temos 2 tipos de datatypes..... 
- **Primitive datatype** (Number, String, Boolean, Undefined, Null, etc.)
- **Objetos**.

Igual no java, aqui também podemos ter objetos do mundo real.

<br>

No Javascript, os objetos se parecem bastante com as Classes no Java. Esses objetos podem armazenar:

- properties (attributes)
- methods

<br>

## Criando um objeto:

```js
let p1 = {
     name: "sasuke",
     age: 44,
     favoriteLanguage: "java"
};

let p2 = {
     name: "itachi",
     age: 33,
     favoriteLanguage: "js",

     mensagemBoasVindas: function(){
          console.log("Sou o itachi fodao!");
     }
};

let p3 = {
     name: "itachi",
     age: 33,
     favoriteLanguage: "js",

     mensagemBoasVindas: () => console.log("Sou o itachi fodao!") //usando arrow function tb funfa!
};

//em todo objeto vamos ter
//propertie : value
```

⚠️ Os objetos no Javascript são parecidos, mas NÃO são iguais aos objetos JSON.

<br>

💡 Viu `{}` bigode/chaves, estamos criando um objeto.

💡 Viu `[]` brackets, estamos criando uma array/lista.

## Acessando um attribute/property de um objeto:

É bem simples. Basta acessar o objeto e depois chamar o attribute/property. `objeto.atributo`.

```js
let p2 = {
     name: "itachi",
     age: 33,
     favoriteLanguage: "js",
     mensagemBoasVindas: function(){
          return "Sou o itachi fodao!";
     }
};

console.log(`Name: ${p2.name}`);
console.log(`Name: ${p2.age}`);
console.log(`Name: ${p2.mensagemBoasVindas()}`);
```


📖 É só pensar que "p2" é a class. Tudo abaixo são os attributes and methods dessa class, sacou?

## Utilizando o `this` para referenciar um attribute do objeto atual
Funciona igualzinho ao Java. Usamos o `this` para referenciar attributes/properties do objeto atual. Nesse caso, do objeto "p2".

```js
let p2 = {
     name: "itachi",
     age: 33,
     favoriteLanguage: "js",

     toStringInsano: function(){
          return `
               Name: ${this.name} \n
               Age: ${this.age} \n
               Favorite language: ${this.favoriteLanguage} \n
          `
     },
};
```

💡 Igualzin ao Java. Usamos para referenciar os attributes ou methods da "Class". Nesse caso, do objeto atual.

## Alterando o valor de um attribute

Igual á um getter() setter() do Java.

```js
let p2 = {
     name: "itachi",
     age: 33,
     favoriteLanguage: "js",

     toStringInsano: function(){
          return `
               Name: ${this.name} \n
               Age: ${this.age} \n
               Favorite language: ${this.favoriteLanguage} \n
          `
     },
};

//alterando o valor da propriedade
p2.name = "goku";
console.log(p2.name); //goku

//alterando o valor da propriedade
p2.name = () => {
     console.log("dale");
     console.log("dale");
     console.log("dale");
}

console.log(p2.name()); //agora a propriedade guarda uma function
```

<br>

No fim, é uma Class que tem attributes e methods. kk

## Criando um objeto mais complexo:

Igual no Java, na nossa Class podemos ter attributes de outras Classes.

```js
let p1 = {
     name: "goku",
     age: 29,
     colors: [
          "blue", "yellow", "red"
     ],
     address: {
          street: "rua tal",
          country: "brazil",
          addressToString: function(){
               //perceba que this faz referencia ao objeto que chamou a funcao. No caso o objeto "address"
               return `
                    Street: ${this.street} 
                    Country: ${this.country}
               `
          }
     }
}

console.log(p1.address);
console.log(p1.address.street);
console.log(p1.address.country);
console.log(p1.address.addressToString());
```

## Evitando NullPointerException

Se voce tentar acessar um attriubte que nao exista no objeto, pode dar pau no seu código e lancar um erro.

Para evitar isso, tu vai usar o topete do elvis `?`

```js
let p1 = {
     name: "goku",
     age: 29
}

console.log(p1.name); //goku
console.log(p1.age); // 29
console.log(p1.atributeNaoExiste1?.atributeNaoExiste1); // undefined safe
```

"Tenta ler isso aí, mas se o que vier antes do ponto for nulo ou indefinido, para tudo e me devolve undefined em vez de explodir um erro".
