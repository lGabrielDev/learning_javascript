## Criando elemento e adicionando no pai

```html
<body>
     <div id="divInsana" class="class1">
          <p>conteudo tal 1</p> 
          <p>conteudo tal 2</p> 
          <p>conteudo tal 3</p> 
          <!-- <p></p>  Ele foi append aqui --> 
     </div>
     <script src="testando.js"></script>
</body>
```

<br>

```js
let pzinhoNovo = document.createElement("p");
     pzinhoNovo.id = "pId";
     pzinhoNovo.className = "class1 estiloInsano1";
     pzinhoNovo.textContent = "conteudo 4";

document.querySelector("#divInsana")
     .appendChild(pzinhoNovo);
```

<hr>
<br>

## Removendo um elemento

```js
let div = document.querySelector("#divInsana");
div.remove();
```

<br>

📖 Se quiser trabalhar com vários 'flhos' basta usar o for() , e suas variacoes, e dale.
