Trabalhando com o DOM, podemos fazer:

- Acessar elementos da nossa pagina HTML
- Adicionar / Remover elementos
- Mudar os attributes desses elementos
- Mudar o style desses elementos

<br>

Para acessar os elementos da nossa pagina html, vamos usar o objeto pai `document` da árvore.

<br>

📖 O objeto `documento` é o pai de todos os elementos de uma página html.

## Acessando elementos do DOM
A maneira mais usada para acessar os elementos do DOM é usando os methods:

- `document.querySelector();` --> Retorna o primeiro elemento que encontrar

- `document.querySelectorAll()` --> Retorna uma lista de elementos

<hr>
<br>

## document.querySelector()

Sempre retorna APENAS 1 elemento. O primeiro elemento que encontrar.

<br>

### Acessando um elemento pelo #id

```html
<body>
     <h2 id="title1" class="class1">salve 1</h2>
     <h2 id="title2" class="class1">salve 2</h2>
     <h2 id="title3" class="class1">salve 3</h2>
     <script src="testando.js"></script>
</body>
```

<br>

```js
//Acessando pelo #id
const elementoInsano1 = document.querySelector("#title1");

console.log(elementoInsano1); //salve 1
```

<br>

### Acessando um elemento pela .class

Vários elementos podem ter a mesma .class, mas o querySelector() SEMPRE vai pegar apenas 1 elemento. O primeiro elemento que encontrar.

```js
//Acessando pela .class
const elementoInsano1 = document.querySelector(".class1");

console.log(elementoInsano1); //salve 1
```

<br>


### Acessando um elemento pela tagName

Vários elementos podem ter a mesma tagName, mas o querySelector() SEMPRE vai pegar apenas 1 elemento. O primeiro elemento que encontrar.

```js
//Acessando pela tagName
const elementoInsano1 = document.querySelector("h2");

console.log(elementoInsano1); //salve 1
```

<hr>
<br>

## document.querySelectorAll()
Retorna uma lista de elementos.

- Concorda que em uma página html podem existir vários elementos com a mesma .class?

- Concorda que em uma página html podem existir vários elementos com a mesma tagName?

<br>

### Acessando elementos da mesma .class

```js
//Acessando todos os elementos da mesma .class
const elementoInsano1 = document.querySelectorAll(".class1");

console.log(elementoInsano1[0]); //salve 1
console.log(elementoInsano1[1]); //salve 2
console.log(elementoInsano1[2]); //salve 3
```

<br>

### Acessando elementos da mesma tagName

```js
//Acessando todos os elementos da mesma tagName
const elementoInsano1 = document.querySelectorAll("h2");

console.log(elementoInsano1[0]); //salve 1
console.log(elementoInsano1[1]); //salve 2
console.log(elementoInsano1[2]); //salve 3
```
