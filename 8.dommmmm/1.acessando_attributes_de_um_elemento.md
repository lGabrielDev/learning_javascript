## Acessando attributes de um elemento

```html
<body>
     <div id="divInsana" class="class1">salve</div>
     <script src="testando.js"></script>
</body>
```

<br>

```js
let div = document.querySelector("#divInsana");

console.log(div.id);
console.log(div.className);
console.log(div.textContent);
```


<hr>
<br>

## Alterando attributes de um elemento

```js
let div = document.querySelector("#divInsana");

div.id = "idDiferente";
div.className = "class2 class3";
div.classList.add("class4");
//div.classList.remove("class4")
//etc...
console.log(div);
```

<br>

⚠️ NÃO altere o style dos elementos. Quem faz isso é o CSS. 

⚠️ Para alterar o style, apenas mude a class desse elemento.


<hr>
<br>

## Alterando o style dos elementos


```css
.estiloInsano1{
     background-color: darkslateblue;
     color: lightblue;
}
```
<br>

```js
let div = document.querySelector("#divInsana");

div.className = "estiloInsano1";
//ou.
//div.classList.add("estiloInsano1")
console.log(div.className)
```

<br>

📖 Quem altera o style dos elementos é o css.
