# Fetch API

Assim como no Java temos o WebClient (ou RestTemplate),, no JavaScript utilizamos a Fetch API para atuar como o nosso "navegador" interno e realizar requisições HTTP.

Cada linguagem possui suas ferramentas nativas para interagir com a rede, e no ecossistema JS, o Fetch é o padrão moderno para essa tarefa.

O Fetch trabalha com Promises (Promessas). Como uma requisição de rede demora, o JavaScript não "tranca" o código esperando a resposta. Em vez disso, ele te entrega uma Promise: um compromisso de que, assim que os dados chegarem, ele executará o que você pediu.

<br>


## Exemplo simples:

Acessando uma api...

```js
let url = `https://rickandmortyapi.com/api/character/13`;


fetch(url) //retorna uma promisse
     // 1. Recebe o "envelope" da resposta (status, headers)
     .then(responseCompleta => responseCompleta.json()) 
     // 2. Extrai e converte os dados do corpo para objeto JS
     .then(corpoEmJson => {
          console.log(corpoEmJson.name);
          console.log(corpoEmJson.location.name);
          console.log(corpoEmJson.location.url);
          //etc...
     });
```

```js
//elementos
let input = document.querySelector("#input");
let button = document.querySelector("#button");
let content = document.querySelector("#content");
let img = document.querySelector("#img");

function buscarDadosApiExterna(personagemId){
     let url = `https://rickandmortyapi.com/api/character/${personagemId}`;

     let dados = fetch(url)
          .then(responseEntity => responseEntity.json()) //retorna uma promise
          .then(body => {return body}) //retorna uma promise
          
     return dados; //dados vai receber uma "promessa" do corpo da requisicao..... se tu der um consolelog agora n vai aparecer nada ....
}


//evento de click
button.addEventListener("click",  (evento) => { //parametro eh informado automaticamente quando o evento acontece.
     evento.preventDefault() //cancacelamos o comportamento padrao do navegador. Eu que vou decidir o que o navegador vai fazer.
     
     let characterId = this.input.value;
     this.buscarDadosApiExterna(characterId)
          .then((body) => { //body é o valor que fica dentro da promessa
               content.textContent = JSON.stringify(
                    {
                         name: body.id,
                         name2: body.name,
                    }, null, 1);

               img.src = body.image;
          });
});

```
