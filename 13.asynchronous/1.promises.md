## Callback hell

Explicar o que é ......

```js
function function1(callback){
     callback();
}

function function2(callback){
     callback();
}

function function3(callback){
     callback();
}

function1(() => {
     function2(() => {
          function3(() =>{}); //etc.....
     });
});
```
