## Callback hell

Muitos callbacks fica dificíl de entender e de dar manutenção.

```js
function function1(callback){
     callback();
}

function function2(callback){
     callback();
}

function function3(callback){
     callback();
}

//callback hell
function1(() => {
     function2(() => {
          function3(() =>{}); //etc.....
     });
});
```

Para evitar isso, surgiu as promises...

## Promises

É um objeto que guarda um valor que ainda vai chegar. Geralmente quando fazemos uma requisicao pra uma API externa, demora um pouquinho pra chegar os dados...

- `resolveCallback`
- `rejectCallback`

<br>


```js
let dadosObtidos = true;

let promessa = new Promise((resolveCallback, rejectCallback) => { //recebe 2 funcoes callback como parametros
     
     if(dadosObtidos){
          resolveCallback("dados obtidos com sucesso!");
     }
     else{
          rejectCallback("erro......");
     }
});

//tenta executar essa 'promessa'
promessa
     .then(resultadoDoResolve => {console.log(resultadoDoResolve)})
     .catch(resultadoDoReject => {console.log(resultadoDoReject)});
```

📖 Igualzinho o try catch no Java....

- Tenta executar isso aqui `then()`...
- Se achar erro, trata `catch()`...

Outro exemplo, só que agora retornando um objeto mais interessante:

```js
let dadosObtidos = true;

let promessa = new Promise((resolveCallback, rejectCallback) => { //recebe 2 funcoes callback como argumento
     
     if(dadosObtidos){
          resolveCallback(
               //poderia criar o objeto antes e passar o nome da variable aqui.... da no mesmo
               {
                    name: "Naruto",
                    age: 33,
                    power: "fire"
               }
          );
     }
     else{
          rejectCallback("erro......");
     }
});

//tenta executar essa 'promessa'
promessa
     .then(pessoa => {
          console.log(pessoa.name);
          console.log(pessoa.power);
     })
     .catch(resultadoDoReject => {
          console.log({
               statusCode: 400,
               errorMessage: resultadoDoReject
          });
     });
```
