## call back

Callback function é uma função passada como argumento para outra função.  

Basicamente, quando voce quer chamar uma function dentro de outra function, voce faz:

<br>

```js
// //tradicional
function printar(resultado){
     console.log(resultado);
}

function somar(n1, n2){
     let result = n1 + n2;
     printar(result); //chamamos uma outra funcao aqui dentro.... Safe
}
somar(20, 20);
```

<br>

Usando callback function, ficaria assim:

```js
//funcao de callback
function printar(resultado){
     console.log(resultado);
}

function somar(n1, n2, callback){
     let result = n1 + n2;
     callback(result);
}

somar(20, 20, printar); //passamos a funcao como argumento
```

<br>

📖 Pode nao fazer sentido agora, mas usamos bastante callback functions quando estamos trabalhando de forma assíncrona.

📖 Callback functions são functions que passamos como argumento em outra funcao.

## Callbacks nos Eventos

Vemos bastante callbacks nos eventos....

A function `addEventListener()` tem 2 parametros....

- "click" --> String
- function()

<br>

```js
const h2 = document.querySelector("#title");

//callback function
function mudarCorElemento(){
     console.log("salve");
}

h2.addEventListener("click", mudarCorElemento); //passamos essa function como argumento
```

<br>

A mesma coisa....

```js
const h2 = document.querySelector("#title");

//callback function
const mudarCorElemento = function (elemento){
     elemento.style.backgroundColor = "red";
}

h2.addEventListener("click", () => { //passamos uma function como argumento da function addEventListener();
     mudarCorElemento(h2);
}); 
```

<br>

A mesma coisa...

```js
const h2 = document.querySelector("#title");

h2.addEventListener("click", () => { // essa funcao anonima / arrow function eh a propria callback em si. sacou?
     h2.style.backgroundColor = "red";
}); 
```

<br>

📖 Callback functions geralmente sao usadas para trabalhar de forma assíncrona. Ou seja, quando a resposta nao é imediada....

 Por exemplo, quando estamos lendo um arquivo, consumindo uma api externa, etc.... Vamos ver isso mais pra frente.
