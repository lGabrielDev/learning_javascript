## Conectando backend frontend

1. Criamos o backend e colocamos o **CrossOrigin** na nossa Controller. Esse CrossOrigin faz a liberação das rotas no nível do navegador.

     Podemos liberar todas as rotas no escopo da Class, ou liberar cada rota de forma individual.

     <br>

     ```java
     @RestController
     @RequestMapping("/api")
     public class SomeController {
          
          @CrossOrigin(origins = "http://127.0.0.1:5500") // <<<<<<<<<<<<-------------
          @GetMapping("/personas")
          public ResponseEntity<List<Person>> showAllPerson(){

               List<Person> personas =  List.of(
                    new Person("rick", 61),
                    new Person("morty", 16),
                    new Person("batman", 33),
                    new Person("pickerick", 44)
               );

               return ResponseEntity.ok().body(personas);
          }
     }
     ```

     💡 Só verificar o endereço exato que seu frontend tá rodando.

     <hr>
     <br>
          <br>

2.  Vamos para o frontend e usamos o Fetch API para simular o navegador. Com ele, conseguimos fazer as requests HTTP.

     ```js
     //buscamos dados do backend
     function buscarDadosApiJavaSpring(){
          let body = fetch( //retorna uma PROMESSA da responseEntity completa.
                    "http://localhost:8080/api/personas",
                    {
                         method: "GET",
                         //outras informacoes do request para enviar.... 
                    }
               )
               .then((responseEntity) => responseEntity.json()); //pegamos apenas o body do responseEntity

          return body; //retorna uma PROMESSA com o corpo da requisicao.
     };
     ```

     💡 Como o fetch é assíncrono, a função retorna uma Promise. Para usar os dados, sempre use o `then`

     - buscarDadosApiJavaSpring().`then`(dados => console.log(dados))
